# Content OS

System do zarządzania treściami - od pomysłu do publikacji.

## Struktura

```
content-os/
├── content/
│   ├── ideas/        → Pomysły na treści
│   ├── drafts/       → Szkice w pracy
│   ├── published/    → Opublikowane
│   └── repurposed/   → Adaptacje social media
├── planning/         → Kalendarz, backlog
├── templates/        → Szablony
└── research/         → Materiały źródłowe
```

## Jak używać z Claude Code

Ten projekt jest przygotowany do pracy z Claude Code.

Pobierz, rozpakuj, i zacznij od:
```bash
cd content-os
claude
/init
```

Resztę zrobimy razem w kursie!
